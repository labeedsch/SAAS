# نظام التقويم الذاتي الذكي – متوسطة لبيد بن ربيعة

مشروع مستقل عن موقع «الخطط الذكية» (labeedsch.github.io/1448)، ويشاركه بيئة العمل: GitHub Pages للواجهة.

## القرارات التقنية (مؤقتة وقابلة للتعديل)
| القرار | السبب |
|---|---|
| واجهة ثابتة على GitHub Pages | نفس بيئة الموقع الحالي |
| Supabase (Postgres + Auth + Storage) كخلفية | GitHub Pages لا يشغّل خادماً، والمتطلبات تحتاج قاعدة بيانات وصلاحيات وملفات خاصة |
| الصلاحيات عبر RLS في قاعدة البيانات | تُفرض على الخادم لا على الواجهة |
| الزائر = دور `anon` بلا حساب | لا دور مستقل باسم «مطلع» |
| مسؤول المؤشر = `staff` بلا حساب | لا يشترط حساباً؛ يُعرض له المؤشر عبر رابط (يُصمَّم في مرحلة واتساب) |
| مستويات التقييم في جدول `evaluation_levels` فارغ | لم يتوفر الدليل بعد، ولا نفترض مستويات أو أوزاناً |
| إصدار الدليل مثبّت في كل دورة (`cycles.guide_version_id`) | لا تتأثر الدورات السابقة بأي تحديث |

## ما اختُبر
- الزائر: يرى الدورة المنشورة والتقييم المعتمد فقط، ولا يرى الشواهد ولا الموظفين، ويرى «بطاقات الحجب» عبر `public_evidence_stubs`.
- المقيم الخارجي: يرى المعتمد في المنشور، ولا يرى منسوبي المدرسة، ولا يعدّل.
- عضو الفريق: يكتب تقييم مؤشره المسند فقط، ولا يعتمد بنفسه.
- مقيم بلا حساب يُرفض.
- سجل النشاط يرفض التعديل والحذف، ولا يقرأه إلا المنسق.
